# 🍔 Queen Burger

Queen Burger adalah aplikasi pemesanan burger berbasis web yang dibuat menggunakan Laravel.
Project ini memiliki fitur login/register, custom burger, cart, dan dashboard sederhana dengan tema hitam-orange aesthetic.

## 🚀 Fitur Utama
* **Dashboard Aesthetic:** Tampilan lobi utama dengan tema Dark & Orange.
* **Authentication:** Sistem Login dan Register untuk keamanan pesanan.
* **Special Request Order:** Custom roti, extra topping (cheese/patty), serta catatan khusus (tanpa bawang, dll).
* **Smart Cart:** Keranjang belanja dinamis yang menghitung total harga secara otomatis menggunakan JavaScript.
* **Simulasi Pembayaran:** Pilih metode pembayaran dan lihat status pesanan (Dimasak -> Siap).

# 📥 Cara Install Project

## 1. Clone Repository

```bash
git clone https://github.com/username/queen-burger.git
```

---

## 2. Masuk Ke Folder Project

```bash
cd queen-burger
```

---

## 3. Install Dependency Laravel

```bash
composer install
```

---

## 4. Install Node Modules

```bash
npm install
```

---

## 5. Copy File Environment

```bash
cp .env.example .env
```

---

## 6. Generate Application Key

```bash
php artisan key:generate
```

---

## 7. Atur Database

Buka file:

```bash
.env
```

Lalu sesuaikan:

```env
DB_DATABASE=queen_burger_db
DB_USERNAME=root
DB_PASSWORD=
```

---

## 8. Jalankan Migration

```bash
php artisan migrate
```

---

## 9. Jalankan Vite

```bash
npm run dev
```

---

## 10. Jalankan Laravel Server

```bash
php artisan serve
```
